# Поиск товаров через LangChain

Консольная программа принимает запросы на русском языке. Модель извлекает категорию, ограничение цены и порядок сортировки. Python проверяет параметры через Pydantic и ищет товары в SQLite.

## Быстрый запуск

Нужен Python 3.10 или новее. Для запросов к модели нужны персональный токен и доступ к университетской сети.

1. Распакуйте архив и откройте терминал в папке с `lab01.py`.
2. Установите зависимости.

   ```powershell
   python -m pip install -r requirements.txt
   ```

3. Откройте файл `.env` рядом с `lab01.py` и впишите токен после `LAB_API_TOKEN=`. Если файла нет, создайте его со следующими полями.

   ```dotenv
   LAB_API_URL=http://10.32.2.11:35000/v1
   LAB_API_TOKEN=
   LAB_MODEL=qwen3.8-27b
   ```

   Храните заполненный `.env` локально. В архиве поле токена оставлено пустым.

4. Запустите программу.

   ```powershell
   python lab01.py
   ```

При первом запуске программа создаст `catalog.sqlite3` и добавит 15 учебных товаров. Вводите по одному запросу. Пустая строка завершает работу.

## Режимы

- `python lab01.py` — модель возвращает параметры в JSON. Для уточнений используется последний валидный набор параметров.
- `python lab01.py --tool` — модель передаёт параметры через вызов инструмента `search_products`.
- `python lab01.py --history` — для уточнений используются предыдущие реплики пользователя.

Попробуйте последовательно в одном сеансе «Покажи ноутбуки до 80 тысяч», «А сначала дорогие?», «А что есть среди смартфонов?». Уточнения сохраняют поля, которые пользователь явно не менял.

## Обозначения

- `category` — категория. `laptop` означает ноутбуки, `smartphone` — смартфоны, `tablet` — планшеты. Для `other` программа сообщает, что категория не поддерживается.
- `max_price` — включительная верхняя граница цены в рублях. `null` означает поиск без ограничения цены.
- `sort_by` — порядок выдачи. `price_asc` показывает сначала дешёвые товары, `price_desc` — сначала дорогие.
- `params` — проверенные параметры запроса, `products` — найденные товары, `message` — итоговое сообщение.

В журнале `llm.start` обозначает начало попытки, `parse.error` — ошибку разбора или проверки, `validation.ok` — успешную проверку, `search.end` — завершение поиска с числом найденных товаров.

## Проверки

```powershell
python experiments.py --out offline.json 2> retry.log
python experiments.py --live --out live.json
```

Первая команда проверяет каталог, обработку ошибок и повторы на имитированных ответах. Вторая запускает эксперименты с университетской моделью.

## Файлы проекта

- `lab01.py` — интерфейс командной строки и цепочки LangChain.
- `catalog.py` — инициализация каталога и поиск по SQLite.
- `experiments.py` — локальные проверки и эксперименты с моделью.
- `requirements.txt` — версии зависимостей.
- `REPORT.md` — отчёт с результатами лабораторной работы.
